# Active Plans

This folder holds implementation plans that are currently in progress for this feature.

## Naming Convention

Use date-stamped names: `{topic}_PLAN_{dd-mm-yy}.md`

Examples:
- `chain-growth_PLAN_25-09-26.md`
- `chain-growth-dune-adapter_PLAN_02-10-26.md`

## What Goes Here

- Plans that are actively being implemented
- Plans that have been approved but not yet started
- Plans waiting for EXECUTE mode approval

## What Does Not Go Here

- Completed plans (move to `completed/`)
- Deferred or future work (move to `backlog/`)
- Reports or references (colocate inside the task folder, not as sibling dirs)

## Lifecycle

1. Plan is created here during PLAN mode
2. Plan is executed during EXECUTE mode
3. After completion and verification, plan moves to `completed/`
4. If deferred, plan moves to `backlog/`
